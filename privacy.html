Privacy policy for Shorts Uploader

Last updated: 9 October 2026

Shorts Uploader is a personal tool that runs on its developer's own computer. The developer is its only user. It is not offered to the public.

What the tool accesses

When the developer signs in with a Google account, the tool uses YouTube API Services to reach the YouTube channels that account manages. It can upload and schedule videos, set thumbnails, list the channel's videos, read and manage comments on them, and read the channel's analytics reports.

What is stored, and where

The sign-in tokens issued by Google are kept in a file on the developer's computer. Video statistics and comments fetched from YouTube are saved on the same computer as report files. Nothing is sent to a server run by this tool, because there is none.

Sharing

No data obtained through the tool is sold, shared with, or transferred to anyone else. It is not used for advertising.

Data about other people

The tool collects nothing from visitors to this page. The only information about other people that it handles is what YouTube already shows publicly on the developer's own videos, such as comments and the names of the people who wrote them.

Removing access

Access can be withdrawn at any time on the Google security settings page, security.google.com/settings/security/permissions. Deleting the token file on the developer's computer also ends the tool's access.

YouTube and Google terms

The tool uses YouTube API Services. Its use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions can be raised as an issue on this site's GitHub repository.
